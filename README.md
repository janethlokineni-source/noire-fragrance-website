# NOIRÉ — The Art of Fragrance

An immersive luxury 3D fragrance showcase experience built with **React**, **Three.js / React Three Fiber**, and **GSAP**.

🔗 **Live Website:** [https://janethlokineni-source.github.io/noire-fragrance-website/](https://janethlokineni-source.github.io/noire-fragrance-website/)  
🎬 **Fragrance Film:** [https://janethlokineni-source.github.io/noire-fragrance-website/film.html](https://janethlokineni-source.github.io/noire-fragrance-website/film.html)  
📦 **GitHub Repository:** [https://github.com/janethlokineni-source/noire-fragrance-website](https://github.com/janethlokineni-source/noire-fragrance-website)

---

## ✨ Features

- **Interactive 3D Perfume Bottle**: Real-time Three.js / React Three Fiber rendering with glass refractive materials, ambient lighting, and rotation.
- **High-Definition Video Experience**: Floating luxury fragrance hero video texture and standalone cinematic film showcase (`film.html`).
- **Complete Visual Assets**: High-resolution bottle imagery, custom typography, luxury dark-gold aesthetics, and responsive layout.
- **Fluid Micro-Animations**: GSAP & Framer Motion transitions across fragrance switching, notes exploration, and cart interactions.
- **Automated CI/CD**: GitHub Actions workflow deploying directly to GitHub Pages on every push.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: GSAP, `@gsap/react`, Framer Motion
- **Icons**: Lucide React
- **Deployment**: GitHub Pages via GitHub Actions (.github/workflows/deploy.yml)

---

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/janethlokineni-source/noire-fragrance-website.git

# Navigate to project directory
cd noire-fragrance-website

# Install dependencies
npm install

# Start development server
npm run dev
```
